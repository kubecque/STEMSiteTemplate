# STEM-PROJECT: ONTWIKKEL EEN WEBSITE OVER JULLIE PROJECT

## Doel
Tijdens dit STEM-project hebben jullie gewerkt rond een onderzoek, ontwerp of technisch probleem. Om jullie werk professioneel voor te stellen, maken jullie een eigen website waarop jullie het volledige project presenteren.

De website moet duidelijk, overzichtelijk en aantrekkelijk zijn voor bezoekers die jullie project nog niet kennen.

---

## Opdracht

Ontwikkel individueel of in groep (volgens de gemaakte afspraken) een website over jullie STEM-project.

De website moet minimaal uit **5 pagina's** bestaan:

### 1. Home
- Titel van het project
- Namen van de groepsleden
- Korte introductie van het project
- Een aantrekkelijke afbeelding of banner

### 2. Probleemstelling
- Welk probleem wilden jullie oplossen?
- Waarom is dit probleem relevant?
- Wat waren de doelstellingen van het project?

### 3. Onderzoek
- Welke informatie hebben jullie verzameld?
- Welke bronnen hebben jullie gebruikt?
- Welke oplossingen hebben jullie onderzocht?

### 4. Uitwerking   
- Beschrijf stap voor stap hoe jullie het project hebben gerealiseerd.
- Voeg foto's, schema's, screenshots of tekeningen toe.
- Vermeld eventuele moeilijkheden en hoe jullie die hebben opgelost.

### 5. Resultaat en reflectie
- Wat is het eindresultaat?
- Werden de doelstellingen bereikt?
- Wat hebben jullie geleerd?
- Wat zouden jullie verbeteren indien jullie meer tijd hadden?

---

## Technische vereisten

De website moet minimaal volgende onderdelen bevatten:

### HTML
- Correcte paginastructuur
- Gebruik van titels, paragrafen, afbeeldingen en lijsten
- Navigatiemenu tussen alle pagina's

### CSS
- Eigen opmaak
- Consistente kleuren en lettertypes
- Verzorgde lay-out

### Extra functionaliteiten (minstens 2)
Kies minstens twee van onderstaande mogelijkheden:
- Tabel
- Contactformulier
- Afbeeldingengalerij
- Video
- Kaart (Google Maps/OpenStreetMap)
- Animaties met CSS
- Responsief ontwerp voor smartphone en tablet
- JavaScript-functionaliteit

---

## Wat moet je indienen?

1. De volledige websitebestanden (HTML, CSS, JavaScript, afbeeldingen, ...)
2. Een ZIP-bestand met alle bestanden.
3. Een werkende versie die lokaal geopend kan worden via `index.html`.


---

## Belangrijk

- Teksten zijn geschreven in correct Nederlands.
- Gebruik eigen afbeeldingen of vermeld de bron.
- Controleer de werking van alle links.
- Lever verzorgd en professioneel werk af.
- Kopiëren van websites of code van anderen leidt tot puntenverlies.
